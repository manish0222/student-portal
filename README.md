# Book Portal

A simple command-line Book Portal application written in C++.

The application allows users to view, search, add, borrow, and return
books.

## Project Goal

This project is being developed as part of a Git lab activity to
practice repository management, branching, merging, file operations,
and Git workflows.

## Features

The Book Portal currently provides the following functionality:

- View all books in the catalog
- Search books by title or author
- Add new books to the catalog
- Borrow available books
- Return borrowed books
- Store book information in a local data file
- Validate menu input and handle invalid choices
